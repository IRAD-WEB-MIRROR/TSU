Iradi keyboard layout

Computing Centre · Department of Iradi Language and Literature

The Iradi (Latin) keyboard layout TSU-98 was made by the university's Computing Centre in 1998, the year after Latin-script Iradi became compulsory in schools, so that the eight letters the English keyboard lacks could be typed without codes. It is the layout used in the university, in most ministries and at the Talas Herald. Revision 3 (2004) is the current one.

Download the layout (ZIP, 5 KB)

Windows, Mac OS X and Linux. Free for any use. Separate files: Windows (.klc) · Mac (.keylayout) · Linux (.xkb)

Yellow keys differ from the English (US) keyboard. Red characters are typed with the right Alt key (AltGr), or Option on a Mac.

Where the letters are

LetterKey
ş Şthe ; key, to the right of L
ı Ithe ' key. Shift gives the capital I (dotless). Capital dotted İ is Shift + i
ö Ö, ü Üthe [ and ] keys, to the right of P
ç Çthe \ key (and the extra key left of Z on European keyboards)
ñ Ñthe ` key, left of 1
ä ÄAltGr + a (Uzbek and Persian words only)
№Shift + 3

The signs that were on those keys are on AltGr. Shift on the number row and the full stop and comma on the / key follow the Russian keyboard, so that typists trained on the old machines did not have to learn their fingers again: Shift + 2 gives ", Shift + 4 ;, Shift + 6 :, Shift + 7 ?. The comma and full stop keys work as before.

Try it

Type here as if the layout were installed. Nothing you type leaves this page.

Press keys as on an English keyboard: kız is k, ', z. For AltGr hold Ctrl and Alt together.

Installing

  • Windows. Open iradi-tsu98.klc in Microsoft Keyboard Layout Creator 1.4 (free from Microsoft), choose Project → Build DLL and Setup Package and run the setup.exe it makes. Then add “Iradi (Latin) TSU-98” under Language in Settings. The Computing Centre's own setup program for Windows 98 and XP is no longer supported.
  • Mac. Copy Iradi-TSU98.keylayout to the Keyboard Layouts folder in your home Library, log out and in, and add it in Input Sources (it is under “Others”).
  • Linux. Copy iradi-tsu98.xkb to /usr/share/X11/xkb/symbols/iradi and run setxkbmap iradi.
  • Telephones. There is no Iradi keyboard for Android or iPhone. Use the Turkish keyboard for ç, ş, ö, ü, ı and İ, and the Kyrgyz one for ñ, or hold down n.

University computers in the library, the reading rooms and the language laboratories have the layout installed; switch with Alt + Shift. Questions: it-help@talasuniversity.org, Computing Centre, main building, room 012.
